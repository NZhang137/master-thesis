# Archived HelpSteer2 M1/C1 Legacy Results

This folder contains earlier HelpSteer2 M1/C1 evaluation outputs from the
relationship-softmax prototype.

These files are kept for traceability, but they should not be cited as the
current thesis-aligned M1/C1 results. The active thesis M1 definition is the
MGDA-inspired one-shot mapping, and the active C1 definition is the
trust-region CAGrad-inspired mapping.

Current coefficient files remain under `results/`:

- `results/helpsteer2_m1_c1_coefficients.csv`
- `results/helpsteer2_m1_c1_coefficients_metadata.json`
- `results/helpsteer2_all_method_coefficients.csv`
- `results/helpsteer2_all_method_coefficients_metadata.json`

The archived CSV, JSON, Markdown, and plot files should be regenerated before
they are used as current experiment evidence.
